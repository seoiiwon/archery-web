# STILLPOINT — Archery, in the elements

localhost에서 실행하는 싱글 플레이 3D 리커브 양궁 게임입니다. Three.js + TypeScript + Vite를 사용하며, 그래픽과 사운드는 로컬에서 생성합니다. 설치 후에는 CDN, 외부 이미지, 폰트, 사운드 API가 필요하지 않습니다.

## 실행

Node.js 20.19+ 또는 22.12+ 환경을 권장합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 주소를 여세요. 기본값은 http://127.0.0.1:5173 입니다.

```sh
npm test          # 물리·판정·경기 진행 테스트
npm run build    # 타입 검사 + 프로덕션 빌드
npm run preview  # dist 빌드 실행
```

## 플레이

- 경기장에서 **좌클릭 유지**: 활시위를 당기며 조준 확대
- 누른 채 **마우스 이동**: 좌우·상하 조준
- **좌클릭 해제**: 발사
- **F**: 버튼을 계속 누르기 어려운 경우 조준 시작 / 발사 전환
- **Esc / 우클릭**: 당기기 취소
- **R**: 조준을 기본 영점으로 복귀
- **M**: 음소거
- 상단 **경기 기록**: 엔드별 기록과 CSV 다운로드
- **설정**: 카메라 추적, 감도, 음량, 새 경기

완전 인장까지 약 1.45초가 필요합니다. 조준기는 완전 인장·표준 공기 밀도·무풍·70m에 맞춰져 있으며 바람을 자동 보정하지 않습니다. 오른쪽으로 부는 바람에는 왼쪽으로 조준을 보정하세요. 4초 이상 당기고 있으면 피로가 증가합니다. 짧은 클릭은 취소되며, 약한 장력으로 발사하면 화살이 표적까지 도달하지 못할 수 있습니다.

브라우저가 포인터 잠금을 허용하면 화면 가장자리에서도 연속 조준할 수 있습니다. 지원하지 않는 환경에서는 포인터 캡처로 동작합니다. 소리는 첫 사용자 입력부터 시작됩니다. 상세 패널은 게임 시간을 일시 정지하며, 다른 창으로 이동하면 당기기는 취소됩니다.

## 경기

- 리커브 70m / 지름 122cm 표적
- 6발 × 12엔드 = 72발 / 최대 720점
- 점수 10–1, 표적 밖 M(0점), 안쪽 10점 X
- 샤프트 반지름 3mm를 포함한 line-cutter 판정
- 엔드마다 바람 재생성, 경기마다 날씨 자동 생성
- 맑음 / 흐림 / 비 / 안개 / 강풍 / 석양
- 6발마다 결과 확인 후 다음 엔드. 끝나면 새 경기를 바로 시작 가능

World Archery의 [타깃 양궁 안내](https://www.worldarchery.sport/sport/disciplines/target-archery) 및 [규정집](https://www.worldarchery.sport/rulebook)을 참고한 **개인 랭킹 라운드**입니다. 실전의 시간 제한, 심판 절차, 동점 순위, 세트제 대진은 적용하지 않습니다. 플레이 도중 새로고침하면 현재 경기는 초기화되므로 보관할 기록은 CSV로 저장하세요.

## 물리

핵심 값은 `src/game/config.ts`에서 관리합니다. SI 단위(미터, kg, N, 초, 라디안)를 사용합니다.

- `F(q) = Fmax × (0.55q + 0.45q²)`, q는 정규화한 당김 길이
- 힘 곡선을 적분한 저장 에너지 × 효율로 발사 에너지 산출
- `v₀ = sqrt(2E / m)`으로 초기 속도 결정
- 고정 240Hz midpoint 적분: 중력, 축 방향 공기 저항, 상대풍의 횡방향 힘
- 시간에 따른 돌풍과 약한 풍향 변화, 고도별 풍속 차이
- 날씨별 공기 밀도, 비 입자, 안개 가시거리, 조명과 환경음
- 한 스텝의 이전/현재 위치를 잇는 선분과 표적 평면 교차로 충돌 판정
- 진행 방향으로 회전하는 화살, 충돌 속도에 따른 관입 깊이

게임용 단순화 모델이며 CFD, 화살의 탄성 진동/아처스 패러독스, 샤프트 간 충돌은 구현하지 않았습니다. 그래픽은 외부 고해상도 스캔을 사용하지 않는 절차적 3D 표현입니다.

## 모듈 구조

```text
src/
  game/
    config.ts            물리·경기·렌더링 설정
    GameManager.ts       경기 상태 머신, 고정 물리 스텝, 이벤트
    Player.ts            플레이어 ID, 이름, 입력 상태
    BowController.ts     당기기, 힘·에너지, 피로, 조준 흔들림
    ArrowPhysics.ts      탄도 적분과 무풍 영점 계산
    TargetSystem.ts      연속 교차 검사와 점수 판정
    WindSystem.ts        엔드별 풍향·풍속과 시간 변화
    WeatherSystem.ts     경기별 기상 생성
    ScoreManager.ts      Player ID 기준 기록 저장
    AudioManager.ts      Web Audio 합성 효과와 환경음
  render/
    SceneBuilder.ts      경기장, 숲, 잔디, 표적, 깃발, 날씨
    BowModel.ts          활·시위·화살·장갑 모델
    CameraController.ts  조준 확대, 반동, 추적/명중 카메라
    RangeRenderer.ts     Three.js 렌더링과 화살 수명 관리
  ui/
    UIManager.ts         HUD, 엔드 결과, 설정, 점수판, CSV
    icons.ts             로컬 SVG 아이콘
  main.ts                입력 연결, 렌더링 루프
  style.css              반응형 HUD 및 패널
```

점수와 발사 기록은 Player 객체가 아닌 `ScoreManager.players: Map<PlayerId, PlayerScore>`에 저장합니다. `GameManager.activePlayerId`를 통해 입력 소유자를 선택하며 향후 2인 턴 제어를 추가할 수 있습니다. 네트워크 동기화 및 실제 2인 플레이는 현재 포함하지 않습니다.

## 검증

`tests/game.test.ts`는 링 경계/라인커터, 장력과 피로, 무풍 영점, 측풍 방향 및 편향, 스텝 간 충돌, 진공 중력, 적분 수렴성, 날씨, 72발/720점 완주와 재시작, 플레이어별 점수 분리를 검증합니다.

데스크톱 브라우저에서 WebGL 하드웨어 가속을 권장합니다. 좁은 화면에서는 명중 미니맵을 숨기고 핵심 HUD를 재배치합니다.
